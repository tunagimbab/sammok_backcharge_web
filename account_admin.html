삼목수추 계정 등록

로그인 계정을 한 번에 만듭니다. 폰·PC 브라우저에서 바로 쓸 수 있고 설치는 필요 없습니다.
먼저 꼭 읽어 주세요 (보안)
  1. Firebase 콘솔 → Authentication → 설정 → 사용자 작업 에서 「생성(가입) 사용 설정」을 잠시 켭니다.
  2. 아래에서 계정을 모두 만든 뒤 바로 다시 끕니다. 켜 둔 동안에는 누구나 계정을 만들 수 있습니다.
  3. 이미 있는 사번은 건너뜁니다(비밀번호 변경 불가). 비밀번호 재설정이 필요하면 콘솔에서 그 계정을 삭제한 뒤 여기서 다시 만드세요.
  4. 결과 표의 비밀번호는 전달 후 지우고, 화면을 닫으면 기록은 남지 않습니다.
비밀번호를 쓰지 않으면 8자리 무작위 비밀번호가 만들어집니다. 직접 지정할 때는 6자 이상.
